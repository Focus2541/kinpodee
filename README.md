# กินพอดี

แอปนับแคลอรี่สำหรับอาหารไทย ใช้งานบนมือถือ ติดตั้งเป็นแอปได้ (PWA) ใช้ออฟไลน์ได้ และถ่ายรูปอาหารให้ AI ประเมินแคลอรี่ได้

## ฟีเจอร์
- คำนวณ BMR (Mifflin-St Jeor), TDEE และเป้าหมายแคลอรี่ต่อวัน (ลดไขมัน / คงน้ำหนัก / เพิ่มน้ำหนัก)
- บันทึกอาหารแยกมื้อ เช้า กลางวัน เย็น ของว่าง
- คลังอาหารกว่า 180 เมนู (อาหารไทย เครื่องดื่มร้านกาแฟ เบเกอรี่ ผลไม้) ค้นหาและกรองตามหมวดได้ เพิ่มเมนูของตัวเองได้
- ถ่ายรูปอาหาร ให้ AI (Gemini) แยกเมนูและประเมินแคลอรี่ แก้ไขก่อนบันทึกได้
- สแกนบาร์โค้ดสดจากกล้อง (BarcodeDetector หรือ ZXing บนเครื่องที่ไม่รองรับ) แล้วดึงข้อมูลจาก Open Food Facts หรือพิมพ์เลขเอง
- พิมพ์ค้นหาได้ทั้งไทยและอังกฤษ (เช่น matcha, latte) สะกดผิดเล็กน้อยก็เจอ ถ้าไม่มีในคลัง ให้ AI ประเมินจากชื่อเมนูได้ แล้วเก็บไว้ในหมวด "ของฉัน"
- พูดชื่ออาหารเพื่อค้นหา (Web Speech API ภาษาไทย)
- ตั้งน้ำหนักเป้าหมายและระยะเวลา แอปคำนวณแคลอรี่ต่อวันและเตือนถ้าเร็วเกิน 1 กก./สัปดาห์
- ติดตามโปรตีน คาร์บ ไขมัน รายวัน สถิติ 7 วัน และกราฟน้ำหนัก

## 1. เปิดแอปบน GitHub Pages
1. อัปโหลดไฟล์ทั้งหมด (ยกเว้นโฟลเดอร์ `apps-script`) ไว้ที่ root ของ repo
2. Settings → Pages → Source: `Deploy from a branch` → branch `main` / `(root)` → Save
3. รอ 1–2 นาที แล้วเปิด `https://<username>.github.io/<repo>/`
4. บน Android เปิดใน Chrome → เมนู ⋮ → "ติดตั้งแอป"

## 2. ตั้งค่าฟีเจอร์ถ่ายรูป (Google Apps Script + Gemini)
API key จะเก็บอยู่ใน Apps Script เท่านั้น ไม่อยู่ในแอปหรือใน GitHub

1. ขอ API key ฟรีที่ https://aistudio.google.com/apikey
2. เปิด https://script.google.com → New project → วางโค้ดจาก `apps-script/Code.gs`
3. Project Settings (ไอคอนเฟือง) → Script properties → เพิ่ม
   - `GEMINI_API_KEY` = key จากข้อ 1
   - `APP_TOKEN` = รหัสลับที่ตั้งเอง เช่น ตัวอักษรสุ่ม 16 ตัว
   - `MODEL` (ไม่ใส่ก็ได้) ค่าเริ่มต้นคือ `gemini-flash-latest`
4. เลือกฟังก์ชัน `testSetup` แล้วกด Run → อนุญาตสิทธิ์ → ดู Execution log ว่าได้ `HTTP 200`
5. Deploy → New deployment → ประเภท Web app
   - Execute as: **Me**
   - Who has access: **Anyone**
6. คัดลอกลิงก์ที่ลงท้ายด้วย `/exec`
7. ในแอป ไปที่แท็บโปรไฟล์ → "ถ่ายรูปด้วย AI" → ใส่ลิงก์และรหัสลับ → กด "ทดสอบการเชื่อมต่อ"

ถ้าแก้โค้ด Apps Script ภายหลัง ให้ Deploy → Manage deployments → แก้ไข → Version: New version (ลิงก์เดิมใช้ต่อได้)

Apps Script จำกัดไว้ 30 รูปต่อชั่วโมง กันโควตาหมดถ้ามีคนอื่นได้ลิงก์ไป ปรับได้ในฟังก์ชัน `rateOk_`

## หมายเหตุ
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ในเครื่องนั้นเท่านั้น
- ค่าพลังงานเป็นค่าประมาณ ค่าจากรูปอาจคลาดเคลื่อน 20–30% ใช้เพื่อดูแนวโน้ม ไม่ใช่คำแนะนำทางการแพทย์
